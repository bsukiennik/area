# Contributing to AREA

## Coding conventions

### Commits

Each commit needs to follow our commit convention:

 - **feat**: New addition
 - **fix**: Bug fix
 - **ref**: Refactoring, improving current code
 - **imp**: Styling only improvements
 - **chore**: All "other" tasks (bumping versions, initialization)
 - **docs**: Documentation changes (Markdown)

### Pull requests

When a main task is done on a branch it can be merge by creating a pull request, this pull request will need to be approved by at lest 1 contributor before being merged.

The name of each pull request should be clear and short, some more description can be added to explain the feature or change.
